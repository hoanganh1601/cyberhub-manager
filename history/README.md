# Tư liệu lịch sử CyberHub

`history/docs/` giữ các tài liệu P0/đợt cũ, phiếu giao việc, báo cáo kiểm thử theo ngày, ảnh nghiệm thu, HTML tham chiếu và CSV nhập Linear. Chúng được chuyển nguyên vị trí tương đối từ `docs/` để giữ bằng chứng và phục vụ đối chiếu Git; không phải hướng dẫn vận hành hiện hành.

Đọc [tài liệu hiện hành](../docs/README.md) trước. Khi một quy tắc trong lịch sử khác với mã nguồn hoặc migration đang chạy, kiểm tra service, SQL và test tương ứng.

[Biên bản kiểm kê và lý do sắp xếp](DOCS_AUDIT_2026-11-17.md).
