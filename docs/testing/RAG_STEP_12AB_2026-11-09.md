## HTTP contract

Cookie đăng nhập và `X-CSRF-Token` lấy từ `/api/session` và `/api/login` hiện có.
Không truyền ID/role/store/prompt/context/request_id từ client.

```http
POST /api/assistant/messages
Content-Type: application/json
X-CSRF-Token: <token sau khi đăng nhập>
X-Language: vi
```

```json
{"question": "Cần gì để mở phiên?", "language": "vi"}
```

API chỉ nhận question 1–2.000 ký tự Unicode và language `vi`/`en` (mặc định vi).
Field ngoài danh sách bị từ chối 422, giới hạn HTTP body vẫn 16 KiB của ứng dụng.
`conversation_id` chỉ được bỏ qua hoặc `null`: chưa có lịch sử server, ID hội
thoại bất kỳ bị từ chối thay vì đọc/ghép nhầm dữ liệu người khác.

Response 200 gồm `answer`, `grounded`, `citations`, `request_id`,
`conversation_id: null`. Citation do RAG core tạo từ chunk được phép, không đọc
file/nguồn do client yêu cầu. UI vận hành sẽ tiếp tục ẩn path/ref mặc định;
metadata nguồn vẫn cần cho kiểm tra. Chưa có endpoint đọc corpus tùy ý.

| Trường hợp | HTTP |
|---|---|
| Thiếu/sai CSRF | 403 trước khi gọi provider |
| Chưa đăng nhập/phiên demo hết hạn | 401 sau kiểm tra CSRF |
| Tài khoản/cơ sở không còn hợp lệ hoặc quyền đổi | 403 |
| JSON/câu hỏi/ngôn ngữ/field không hợp lệ | 422 |
| Body quá lớn | 413 |
| Chưa bật feature | 503 `ASSISTANT_DISABLED` |
| Hết hạn mức | 429 `RATE_LIMITED`, có `Retry-After` |
| Thiếu căn cứ/điểm thấp | 200, `grounded=false`, citation rỗng |
| Timeout/provider/index/audit lỗi | 503, không trả lỗi nội bộ/model output |

Các response API có `Cache-Control: no-store`. Lỗi xác thực dùng handler hiện
có; request_id của API/service/audit dùng chung UUID backend sinh. ID lỗi trước
khi admission không được dùng để yêu cầu đọc lịch sử.

## Hạn mức và audit bền vững

`ai/policy_store.py` cung cấp adapter **một host, file SQLite trên ổ bền vững**:

- Mặc định 10 request/phút/actor, 100 request/ngày/actor, 1.000/ngày toàn app.
- Phút/ngày là cửa sổ cố định UTC. Account và employee có namespace riêng.
  Đổi role, ngôn ngữ, cơ sở, đăng nhập lại không reset hạn mức cùng actor.
- `BEGIN IMMEDIATE` kiểm tra toàn bộ hạn mức và ghi `ACCEPTED` trong cùng
  transaction trước khi embedding/generation. Worker cùng host dùng chung file.
- Request đã nhận vẫn tính hạn mức khi timeout/fallback/lỗi; không tự retry
  provider. Worker runner/deadline của RAG core vẫn áp dụng.
- Nếu tiến trình dừng giữa chừng, `ACCEPTED` còn lại biểu thị chưa hoàn tất,
  không giả thành answer thành công và không mất quota khi khởi động lại.
- Audit chỉ có request ID, actor type/ID/role, scope, ngôn ngữ, chunk IDs, kết
  quả và thời gian. **Không lưu question, answer, prompt, mật khẩu hoặc API key.**
- Ghi audit cuối thất bại thì giữ trạng thái chưa hoàn tất và trả 503; admission
  thất bại thì không gọi provider. Không log exception provider hoặc raw text.
- Dọn metadata quá 30 ngày khi nhận request mới; chưa có lịch sử chat/feedback.
- File phải là đường dẫn tuyệt đối, ngoài thư mục web/assets; quyền file 0600
  trên Linux. Đây là dữ liệu vận hành riêng, không phải tài nguyên public.

**Giới hạn triển khai:** SQLite này dùng cho review/local hoặc một host có ổ
bền vững, không phải limiter phân tán. Trước triển khai nhiều container/host,
phải thay bằng adapter DB chung (ví dụ MySQL) và kiểm thử lại tính nguyên tử.
Không đặt mỗi replica một file hoặc đặt trên filesystem tạm của hosting.
Giới hạn request chưa thay thế giới hạn token/chi phí của adapter LLM thật.

## Cấu hình backend

Mặc định `ASSISTANT_ENABLED=False`; không mở file audit hoặc khởi tạo model.
Chỉ bật qua composition root sau khi model/ngưỡng/nguồn đã được review:

```python
from cyberhub_manager.ai.policy_store import AssistantLimits
from cyberhub_manager.ai.service import RAGAssistantService
from cyberhub_manager.web import create_app

def assistant_factory(audit_sink):
    # retriever và llm là adapter được backend cấu hình, không lấy từ request.
    return RAGAssistantService(retriever, llm, audit=audit_sink)

app = create_app({
    "ASSISTANT_ENABLED": True,
    "ASSISTANT_SERVICE_FACTORY": assistant_factory,
    "ASSISTANT_AUDIT_PATH": "/var/lib/cyberhub/assistant/audit.sqlite3",
    "ASSISTANT_LIMITS": AssistantLimits(),
    # Thêm WEB_MODE/SECRET_KEY/cấu hình deployment của ứng dụng hiện có.
})
```

Đây là cấu trúc composition, không phải lệnh bật AI ngay: `retriever`/`llm`
thật chưa được chọn. Tests inject fake provider và file audit trong `tmp_path`.
Không dùng baseline TF-IDF/trích đoạn làm mô hình production.
