# Bundled desktop fonts

Inter (400, 700) and Space Grotesk (400, 700) are distributed under their included
SIL Open Font Licenses. These static TrueType files are loaded privately for the
current process by CustomTkinter; users do not need to install fonts manually.

Sources: Google Fonts CSS API (`fonts.googleapis.com/css`), binaries hosted on
`fonts.gstatic.com`. Licenses: Google Fonts repository, `ofl/inter/OFL.txt` and
`ofl/spacegrotesk/OFL.txt`.

The Login uses Inter for body/input text and Space Grotesk for headings/labels,
matching the supplied Stitch HTML. All login icons and circuits are drawn locally.
